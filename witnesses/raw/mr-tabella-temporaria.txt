#   the book's own table of the movable feasts, year by year from 1960 to 2011.
#   It is the verification set for `kalendarium/`: the computation is held
#   against the edition this project follows, rather than against a modern
#   almanac that follows the same arithmetic for different reasons.
# source: https://archive.org/details/missale_romanum-1962
# path: printed page XLII (scan leaf n43), 600 dpi colour scan

# orthography: 1962 liturgical; the month names are the book's abbreviations
#   (ian., febr., mart., apr., maii, iunii, nov., dec.)
# note: transcribed from the PAGE IMAGE. The scan's text layer breaks the
#   figures in this table beyond use -- it prints "2 6 maii", "*4", "$ iunii"
#   and "x3" for ordinary numerals -- and a table of numbers read out of it
#   would verify nothing.
# note: the columns kept here are the ones the temporal cycle needs. The
#   printed table also carries the dominical letters, the golden number, the
#   epact and the indiction, which belong to the computus rather than to the
#   day a reader is looking for.
# corrigendum: 1960-2011 Dominicae post Pentecosten -- the 1996 cell prints
#   16, which cannot be right: the count runs 23 to 28 (2011 is 23, 1967 is
#   28), and with Pentecost on 26 May and the First Sunday of Advent on 1
#   December that year holds 26 Sundays. Transcribed as printed and marked
#   here rather than silently corrected. Every other cell of the 52 rows --
#   416 values -- agrees with the computation.
#
